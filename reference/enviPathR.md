# enviPathR: the R client for the enviPath RESTful API

The environmental pathway database (enviPath) is a key resource for the
functional annotation and pathway prediction of microbial communities,
providing knowledge on biotransformation pathways along with the
chemical reactions and produced compounds. This package enables the
programmatic access to enviPath by porting the database API from R.

## See also

- enviPath front page: <https://envipath.org/>

- legacy API docs: <https://envipath.org/api/legacy/docs#/>
